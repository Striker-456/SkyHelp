Diseña tres nuevos módulos para una plataforma web CRM llamada **SkyHelp**, manteniendo una interfaz moderna, profesional, limpia y consistente con un sistema empresarial de gestión y soporte.

La aplicación debe utilizar un diseño tipo **Dashboard administrativo**, con navegación lateral persistente, encabezado superior y área principal de contenido. El diseño debe transmitir profesionalismo, tecnología, confianza y facilidad de uso.

## Contexto general

SkyHelp CRM es una plataforma diseñada para gestionar usuarios, solicitudes o tickets, roles, auditorías, reportes y estadísticas.

Los nuevos módulos que se deben diseñar son:

1. Auditorías
2. Reportes
3. Estadísticas

Mantén una estructura visual consistente entre los tres módulos y asegúrate de que la experiencia sea intuitiva para usuarios administrativos.

---

# 🔍 MÓDULO DE AUDITORÍAS

Diseña una página llamada **Auditorías** que permita visualizar y controlar las acciones realizadas dentro del sistema.

### Elementos principales:

* Título principal: **Auditorías**
* Texto descriptivo: “Consulta y realiza seguimiento a las acciones realizadas dentro del sistema.”
* Barra de búsqueda para encontrar registros.
* Filtros por:

  * Usuario
  * Acción realizada
  * Módulo
  * Fecha
* Tabla principal de auditorías.

### La tabla debe incluir las siguientes columnas:

* Fecha y hora
* Usuario
* Acción
* Módulo
* Descripción
* Dirección IP
* Acciones / Detalles

Cada registro debe mostrar etiquetas visuales o badges para diferenciar acciones como:

* Crear
* Actualizar
* Eliminar
* Inicio de sesión
* Cierre de sesión

Agregar un botón o icono para **ver detalles completos de una auditoría**.

El diseño debe facilitar la trazabilidad, el control y la seguridad de las actividades realizadas dentro de SkyHelp.

---

# 📄 MÓDULO DE REPORTES

Diseña una página llamada **Reportes** orientada a la generación y consulta de información del sistema.

### Elementos principales:

* Título: **Reportes**
* Descripción: “Genera y consulta reportes para analizar la información del sistema.”
* Sección de filtros para seleccionar:

  * Tipo de reporte
  * Rango de fechas
  * Usuario
  * Estado
  * Categoría

### Incluir tarjetas o categorías de reportes:

* Reporte de tickets
* Reporte de usuarios
* Reporte de actividad
* Reporte de auditorías
* Reporte de rendimiento

Cada tarjeta debe incluir:

* Icono representativo
* Nombre del reporte
* Breve descripción
* Botón “Generar reporte”

Agregar una sección de **reportes recientes**, mostrando:

* Nombre del reporte
* Fecha de generación
* Usuario que lo generó
* Estado
* Opciones para visualizar o descargar

Incluir botones para exportar los reportes en formatos como:

* PDF
* Excel
* CSV

El diseño debe verse profesional y enfocado en análisis y toma de decisiones.

---

# 📊 MÓDULO DE ESTADÍSTICAS

Diseña una página llamada **Estadísticas**, enfocada en la visualización y análisis detallado de los datos de SkyHelp CRM.

### Encabezado:

* Título: **Estadísticas**
* Descripción: “Analiza el rendimiento y comportamiento de la información registrada en el sistema.”
* Selector de rango de fechas.

### Incluir tarjetas de indicadores principales:

* Total de tickets
* Tickets resueltos
* Tickets pendientes
* Usuarios activos
* Tiempo promedio de resolución
* Nivel de rendimiento

### Incluir diferentes visualizaciones gráficas:

* Gráfico de tickets creados por período.
* Gráfico circular con la distribución de tickets por estado.
* Gráfico de barras con tickets por categoría.
* Gráfico de rendimiento o productividad.
* Comparativa entre tickets resueltos y pendientes.

También incluir una sección llamada **Resumen de rendimiento**, mostrando indicadores relevantes y tendencias del sistema.

Los gráficos deben tener un diseño moderno, limpio y fácil de interpretar.

# 🎨 ESTILO VISUAL GENERAL

Mantener una interfaz consistente con un CRM moderno y profesional:

* Diseño minimalista y empresarial.
* Dashboard con sidebar lateral.
* Espaciado amplio y buena jerarquía visual.
* Tarjetas con bordes sutiles y sombras suaves.
* Tablas modernas y fáciles de leer.
* Botones claros y consistentes.
* Iconografía moderna.
* Badges para representar estados y acciones.
* Diseño responsive para escritorio y dispositivos móviles.

Utilizar una jerarquía visual clara para diferenciar:

* Información importante
* Indicadores
* Acciones principales
* Filtros
* Datos secundarios

El resultado debe parecer una plataforma SaaS profesional de nivel empresarial, similar a un CRM moderno utilizado por organizaciones para gestionar soporte, usuarios, actividad y análisis de información.

Mantener consistencia visual con los módulos existentes de SkyHelp CRM, evitando rediseñar completamente la identidad de la aplicación. Los nuevos módulos deben sentirse como una extensión natural del sistema existente.
